# Calculator App
A simple command-line calculator written in Python.

Run: `python3 calculator.py`

## About
Lab assignment for the **Cloud & DevOps (UCS745)** course at Thapar Institute.

The goal was to practise Git branching and merge-conflict resolution:
- Built the base calculator (`+ - * /`) on `main`.
- Added power (`^`) on `feature-power` and modulus (`%`) on `feature-modulus`, both editing the same lines.
- Merged `feature-power`, then merged `feature-modulus` to trigger a conflict.
- Resolved the conflict by hand, keeping both features, and pushed all branches.
